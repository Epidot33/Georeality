\# AI Usage



Author: Jonas Bermin - WSP



\## Purpose



This document describes how AI-assisted development may be used within the GeoReality project.



GeoReality may use AI assistance for drafting documentation, suggesting software structure, generating boilerplate code, improving comments, proposing tests and supporting code review.



AI assistance is used as a development support tool. It does not replace human understanding, review, validation or responsibility.



\---



\## Project Author



The default project author is:



Jonas Bermin - WSP



The project author is responsible for defining the project direction, reviewing generated material, validating scientific and technical assumptions, and approving content before use.



\---



\## Development Approach



GeoReality uses an AI-assisted development workflow.



AI may be used for:



\- Drafting documentation

\- Suggesting architecture

\- Creating boilerplate code

\- Improving comments and docstrings

\- Proposing test cases

\- Reviewing code structure

\- Explaining technical concepts

\- Suggesting refactoring options



AI assistance must not be used as a replacement for engineering judgement.



\---



\## Review Requirements



All AI-generated or AI-assisted material must be reviewed before it is accepted into the project.



This includes:



\- Source code

\- Documentation

\- Configuration files

\- Metadata descriptions

\- Test cases

\- Processing logic

\- Scientific assumptions



The reviewer must ensure that the material is understood, relevant, correct and suitable for the intended purpose.



\---



\## Code Responsibility



All generated code must be:



\- Reviewed

\- Understood

\- Tested

\- Checked for security issues

\- Checked for licensing or intellectual property concerns

\- Validated against project requirements

\- Documented where necessary



Generated code shall not be treated as correct simply because it appears plausible.



\---



\## Security



GeoReality must follow secure development principles.



Sensitive information must never be stored directly in source code.



This includes:



\- Passwords

\- API keys

\- Access tokens

\- Certificates

\- Connection strings

\- Client confidential information

\- Project confidential information



Secrets must be stored using approved secure storage mechanisms.



\---



\## Dependencies



Third-party libraries may be used when they provide clear value to the project.



For each important dependency, the project should document:



\- Library name

\- Purpose

\- Version

\- License

\- Reason for use

\- Main project components using the library



The project author is not expected to review the full source code of every third-party dependency, but the selected libraries should be established, suitable for the purpose, and used in a controlled way.



\---



\## Scientific and Technical Validation



GeoReality handles geospatial, environmental, hydrogeological and geophysical data.



Therefore, AI-assisted outputs must be validated with particular care when they affect:



\- Coordinate transformations

\- Interpolation

\- Mesh generation

\- Geospatial positioning

\- Environmental interpretation

\- Hydrogeological interpretation

\- Geophysical interpretation

\- Data visualization scale

\- Project metadata



Scientific and engineering assumptions must be explicit and traceable.



\---



\## Traceability



GeoReality should maintain traceability for:



\- Input files

\- Coordinate reference systems

\- Processing steps

\- Data sources

\- Generated models

\- Exported files

\- Project metadata

\- Author information



Default author metadata:



Jonas Bermin - WSP



\---



\## Human Approval



AI-assisted content is only considered accepted when it has been reviewed and approved by the project author or another responsible reviewer.



Approval means that the reviewer has checked that the material is understandable, relevant and appropriate for the project.



\---



\## Summary



AI may help accelerate GeoReality development, but responsibility remains human.



The guiding principle is:



Use AI to draft faster.



Use human review to build correctly.
